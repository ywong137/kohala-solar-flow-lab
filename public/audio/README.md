# Wind audio

`wind-loop.mp3` is the “Steady wind” recording from the SSE Library: WIND archive.

- Source: https://archive.org/details/SSE_Library_WIND
- Collection: USC Cinema / Sunset Editorial Collection
- License: CC0 1.0 Universal
- Original archive file: `GENERAL/WIND_Steady wind_CS_USC.mp3`

The site copy is trimmed to one period and crossfaded at the source seam for continuous looping.
